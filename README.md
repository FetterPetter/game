# Vampire Survivor-like

Et lite spill inspirert av _Vampire Survivors_.  
Spillet er laget med **React** og bruker **OpenLayers** til å tegne spilleren, fiender og styre dem.

[Spill her på GitHub Pages](https://fetterpetter.github.io/game/)

---

## Hvordan spille

1. Klikk på **"Velg spawn"**-knappen og trykk et sted på kartet for å starte.
2. Beveg deg rundt med:
   - **WASD** eller **piltastene**
3. Drep fiender for å samle XP og **level opp**.
4. Velg nye **abilities** når du levler.
   - Eksempel: lærer du **Dash**, bruker du **Space** som hotkey for å dashe.
5. **Highscore** og **musikkvolum** lagres lokalt i nettleseren.

---

## Teknologi

- **React** rammeverk for selve spillet
- **OpenLayers** håndterer kart, spiller, fiender og bevegelse
- **LocalStorage** lagring av highscore og musikkvolum

---

## Features

- Spillerkontroll med tastatur
- Fiender som jakter på deg
- Leveling system med valg av abilities
- Dash funksjon (hotkey: `Space`)
- Lokal lagring av musikkvolum og highscore
